## What I'm working on

### [ASMR Platformer](https://github.com/LeQuiD122/asmr-platformer)

A 3D Roblox platformer with 26 tactile materials across 4 levels. Soap crumbles under you,
wax cracks, bubble wrap pops.

<img src="https://raw.githubusercontent.com/LeQuiD122/asmr-platformer/main/screenshots/soap-crumble.gif" width="420">

Written in Luau, with Python scripts that generate the 3D meshes in Blender and check the
code before it goes into the game.
